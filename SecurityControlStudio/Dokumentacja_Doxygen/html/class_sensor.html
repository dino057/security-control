Detailed Description

Skanuje pokoj i weryfikuje uprawnienia przebywajacych w nim osob.

  • Czujnik jest przypisany do konkretnego pokoju i podlaczony do glownego systemu alarmowego, ktory powiadamia w razie wykrycia intruza.
