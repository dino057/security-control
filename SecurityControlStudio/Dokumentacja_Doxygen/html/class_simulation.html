Detailed Description

Glowny menedzer symulacji. Zarzadza czasem (krokami), postaciami i budynkiem.

  • Klasa laczy wszystkie elementy w calosc. Odpowiada za wczytywanie mapy, usuwanie dynamicznych obiektow z pamieci, oraz za glowna petle logiki gry (metoda step).
