Detailed Description

Reprezentuje autoryzowanego pracownika przebywajacego w budynku.

  • Klasa dziedziczy po abstrakcyjnej klasie Person. Pracownik posiada identyfikator RFID, ktory zapewnia mu staly, legalny dostep do pomieszczen.
