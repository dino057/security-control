Detailed Description

Dziennik zdarzen przechowujacy komunikaty tekstowe.

  • Klasa zbiera informacje o wszystkich akcjach w budynku (ruchy postaci, wlaczenie alarmow, zhakowanie drzwi) i pozwala na ich seryjne odczytanie.
